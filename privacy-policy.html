개인정보처리방침

최종 수정일: 2026년 11월 3일

식단 영양 계산기(이하 '앱')는 사용자의 개인정보를 중요하게 생각하며, 관련 법령을 준수합니다.

1. 수집하는 개인정보 항목

본 앱은 사용자의 주민번호, 이름, 연락처 등 고유식별정보를 일절 수집하거나 중앙 서버로 전송하지 않습니다.

  • 식단 사진 및 기록 데이터: 사용자가 업로드한 사진 및 식단 입력 데이터는 전적으로 사용자의 기기 로컬 저장소(LocalStorage)에만 저장됩니다.
  • Gemini API 키: 사용자가 AI 분석을 위해 직접 입력한 API 키는 기기 내에 암호화되지 않은 로컬 저장소에 보관되며, Google Gemini API 요청 시에만 Google 서버로 직접 전송됩니다.

2. 권한 사용 목적

  • 인터넷 (INTERNET): Tailwind CSS 및 웹 리소스 로드, 그리고 사용자가 Gemini AI 분석 요청 시 API 서버와의 통신에 사용됩니다.
  • 사진/파일 접근 (READ_EXTERNAL_STORAGE): 사용자가 식단 사진을 선택하여 화면에 표시하고 영양을 분석하기 위해 사용됩니다.

3. 제3자 제공 및 위탁

본 앱은 이용자의 동의 없이 개인정보를 외부에 제공하거나 판매하지 않습니다. 단, AI 사진 분석 기능을 이용할 경우 해당 사진 데이터는 사용자가 설정한 키를 통해 Google Gemini API로 전송될 수 있습니다.
